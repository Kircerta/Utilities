# Brownoiser

- Name: Brownoiser
- Description: Brown-noise tray app.
- Tech Stack: Python, pygame, pystray, Pillow, PyInstaller.
- Build From Source: `python3 -m pip install pygame pystray pillow pyinstaller`; `pyinstaller --onefile --windowed --add-data "brownnoise_sample1.wav:." --add-data "brownnoiser_winicon.ico:." brownoiser.py`
